How I Structure a Post

An example tutorial style post with headings and code blocks.

· ❦ ·

A consistent structure makes writing faster.

1) Draft the headline first

Write five headline options, then choose the clearest one.

2) Start with a promise

Tell readers exactly what they will learn.

3) Add a concrete example

# Example workflow for local publishing
hugo server -D

4) End with action

Give readers one thing to do next.
